# Herramientas de datos

- `off_query_list.json`: lista de ingredientes y aditivos de la base de NutriSafe con su etiqueta de Open Food Facts
  (`en:...`). Sirve para calcular «Suele encontrarse en» a partir de los productos de Open Food Facts que los contienen.
- `found_in.json`: resultado — para unos 2 700 ingredientes y aditivos, las categorías de producto (de una lista de 76) en las que más aparecen, a partir de una muestra de hasta 300 productos de Open Food Facts por ingrediente (búsqueda en search.openfoodfacts.org, octubre de 2026). Datos de Open Food Facts, licencia ODbL.
